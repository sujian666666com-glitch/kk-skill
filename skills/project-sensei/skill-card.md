## Known Risks and Mitigations:

Risk: Generated setup, dependency, database, or run commands may be incorrect or unsafe for the specific project being analyzed.

Mitigation: Review commands and configuration changes before running them, especially when they install dependencies, start services, or modify local project state.

Risk: The skill produces very detailed beginner guidance, which can over-explain or miss project-specific constraints if the project evidence is incomplete.

Mitigation: Check the generated journal or run diary against the actual project files and update any assumptions before relying on it for onboarding or execution.
