# 范围与异常排查（FAQ）

本文件澄清本技能的能力范围边界与常见异常的处理方式。用于生成前判断「该不该画」与「画不了时怎么回」。

## 一、能力范围（✅ 支持 / ❌ 不支持）

**✅ 支持**
- 系统 / 微服务 / 分层架构图
- 网络拓扑图
- 业务流程图 / 数据流图
- 时序图 / 状态机图
- ER 图 / 类图
- 甘特图（任务时间轴）
- 输出形态：自包含 HTML、内联 SVG、Mermaid 代码块

**❌ 不支持（遇到必须「说明 + 原因 + 替代」，再等确认）**
- 统计图：饼图、柱状图、折线图、散点图
- 3D 渲染 / 真实地理地图
- 思维导图（自由发散树）
- 直接导出 PNG / PDF（需用户在浏览器另存 / 截图）
- 反向工程：由图生成源代码
- 实时数据接入 / 外部 API 拉取

> 硬规则：落到 ❌ 区，**先说「不支持 + 原因 + 替代方案」，再等用户确认**，不硬画、不假装支持。

## 二、常见异常与处理

**Q1：用户要画饼图 / 折线图？**
→ 不支持统计图。说明原因（本技能聚焦结构关系图，非统计可视化），建议改用 Excel / 专用图表工具；若只是想在架构旁附一张趋势图，可降级为「文字 + 表格」说明。

**Q2：用户给了文件路径 / 专有名词，要我直接画？**
→ 先读取并拍平为自包含语义（解引用一切），禁止只列词成框。若文件不在用户显式指定范围内，先征求路径确认。

**Q3：节点太多（>20）放不下？**
→ 一图一主题。提议按子域 / 层级拆分多张图，或走确认门用 scenarios 高亮单条链路、淡化其余。

**Q4：要导出 PNG / PDF？**
→ 不支持直出。HTML 让用户浏览器「打印 / 另存为 PDF」或截图；内联 SVG 可让用户复制后自行保存。

**Q5：要由架构图反推代码？**
→ 不支持反向工程。可改为「基于本图，给出模块职责清单（文字）」辅助手写。

**Q6：图类型不清 / 用户混说？**
→ 澄清三问（输出形态 / 图类型 / 范围）；有歧义复述确认，如「你说的是业务流程图，对吗？」

**Q7：多视图 / 大幅调整要不要先问？**
→ 要。走确认门：先输出推荐方案（拆分机制 + 各视图焦点 / 层级 + 理由）并等用户明确确认，未确认不落笔。优先 scenarios（单数据源 + 高亮目标链路、淡化无关），优于复制多份完整图。

**Q8：渲染出来压字 / 重叠？**
→ 见 `references/self-check-and-errors.md` 的四段式与修复对照表，先归因再修复并复检。

## 三、判断口诀

> 结构关系能画，统计地理不画；文件名词先拍平，压字重叠先复检；
> 不支持先说清，多视图先确认；一图一主题，降级有替代。
