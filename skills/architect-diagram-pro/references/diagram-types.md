# 图类型最佳实践 → 反模式 → 骨架

每种图类型给出三件套：**最佳实践**（照做）、**反模式**（别做）、**骨架**（可直接套用的 SVG/Mermaid 起点）。内联 SVG 一律 viewBox `0 0 680 <height>`，宽 680px；Mermaid 用于类图/甘特/需进文档的场景。

---

## 1. 分层架构图（系统 / 微服务 / 云原生）

**最佳实践**：按「接入层 → 应用层 → 数据层 → 基础设施」分层，每层虚线圆角框包裹，层间箭头 ≥40px（见 architecture-layout.md）。
**反模式**：所有组件平铺无分组；层间箭头压住框边；节点超 20 个不拆分。
**骨架**：
```svg
<svg viewBox="0 0 680 360" width="100%">
  <rect x="40" y="40" width="600" height="80" rx="12" fill="none" stroke="#d4d1c7" stroke-dasharray="6 4"/>
  <text x="56" y="62" font="500 13px sans-serif" fill="#6b6961">L1 接入层</text>
  <rect class="node" x="80" y="80" width="140" height="44" rx="10"/>
  <text class="node-t" x="150" y="106">网关</text>
  <!-- 下层同理；层间 path + marker -->
</svg>
```

## 2. 网络拓扑图

**最佳实践**：节点=设备/服务，连线=链路；用圆/六边形区分设备类型，图例说明形状含义。
**反模式**：节点与连线无图例；连线交叉无说明；IP/端口标签压在连线上。
**骨架**：节点用 `<circle>`/`<rect>`，链路用 `.edge` + `marker-end`，标注放两列 gap + 白底衬底（见 arrow-text-clearance.md）。

## 3. 业务流程图 / 泳道图

**最佳实践**：开始/结束用圆角矩形，步骤用矩形，判断用菱形，流向用箭头；多角色用泳道横向分区。
**反模式**：判断菱形无「是/否」分支标注；流程无起点终点；箭头方向混乱。
**骨架**：Mermaid `flowchart TD` 或内联 SVG `<rect>`+`<polygon>`(菱形)+`marker`。

## 4. 数据流图

**最佳实践**：数据源 → 处理 → 存储 → 输出，单向箭头清晰；处理用圆角矩形，存储用开口矩形（数据库符号）。
**反模式**：数据流双向混淆；处理与存储符号混用；缺少数据终点。
**骨架**：内联 SVG，处理节点 `.node` + 存储 `<rect>` 双线底，箭头标数据名。

## 5. 时序图

**最佳实践**：顶部角色 lifeline 竖线，消息用水平箭头 + 序号；自调用用回环箭头。
**反模式**：消息无序号；lifeline 缺失；返回消息与请求箭头不分（虚线=返回）。
**骨架**：Mermaid `sequenceDiagram` 或内联 SVG（竖线 + 水平 `<path>` + `marker`）。

## 6. 状态机图

**最佳实践**：圆角矩形状态 + 转换箭头（标注触发事件），初态用实心圆，终态用同心圆。
**反模式**：转换无事件标注；状态可重入无说明；初/终态缺失。
**骨架**：内联 SVG `<rect rx="20">` 状态 + `<path>` 带 `marker-end`，箭头旁标事件。

## 7. ER 图

**最佳实践**：实体矩形 + 属性列表，关系菱形 + 基数（1:N, N:M）；主键加下划线。
**反模式**：关系无基数；属性与实体混排；多对多未拆中间表。
**骨架**：Mermaid `erDiagram` 或内联 SVG（实体矩形分两栏 + 关系 `<polygon>` 菱形）。

## 8. 类图 / 甘特图（走 Mermaid）

- 类图：`classDiagram`，类名 + 属性 + 方法，继承/关联用对应箭头。
- 甘特：`gantt`，按阶段/任务排期；非 SVG 轨道。

## 反模式速查清单（绘制前后对照）

- [ ] 分层图无分组框 / 层间箭头压框 → 加虚线框、箭头留 40px
- [ ] 拓扑图无图例 → 右下角补形状/颜色图例
- [ ] 流程判断无分支标注 → 菱形两端标「是/否」
- [ ] 时序无序号 / 无 lifeline → 补序号与竖线
- [ ] 状态机转换无事件 → 箭头旁补触发事件
- [ ] ER 无基数 → 关系线补 1:N / N:M
- [ ] 任何图箭头压字 → 套用 arrow-text-clearance.md
- [ ] 节点 >20 → 拆 scenarios / 多视图（clarification-gate.md）
