# 文字避让规范（关键！）

箭头/连线与文字重叠是结构图最常见的翻车点。根因是缺少「箭头与文字重叠」的硬约束，导致标注与连线共线、箭头盖字。

## 黄金法则

| 规则 | 数值 |
|------|------|
| 箭头尖端落点周围 **10px 半径禁区**内禁止放任何文字 | 10px |
| 文字与连线净空 | ≥6px |
| 箭头在节点边框前停止（留间隙） | ≥12px |
| 同区两条线之间净空 | ≥20px |
| 白底衬底外延（防压字兜底） | 3px |

- **标注进留白/节点内**：地址、序号等注释放进两列 gap 或节点框内；箭头在节点边框前停止（留 ≥12px 间隙），不压字。
- **白底衬底**：凡文字可能与连线共区，先画 `fill="#ffffff"` 矩形衬底再画文字，彻底防压字。白底也用 `.bg{fill:#fff}` 类复用（见 svg-efficient-template.md）。
- **线与线/线与字净空**：文字与连线 ≥6px，同区两线 ≥20px。

## 标注放置策略

- **序号注释**：侧上/侧下方留白 + 白底衬底。
- **数据包地址**：放进两列之间的 gap + 白底衬底，不正对箭头。
- **节点内文字**：箭头只到框边，不进框内压字。

## 出图前自查清单（5 条必过项）

- [ ] 箭头尖端 10px 禁区内无文字
- [ ] 文字与连线 ≥6px
- [ ] 箭头在节点框前 ≥12px 处停止
- [ ] 同区两线 ≥20px
- [ ] 凡文字可能与连线重叠处，已先画白底衬底
