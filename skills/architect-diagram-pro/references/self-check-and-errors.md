# 渲染前自检与出错重试

本文件给出生成前的逐条自检表，以及出错后的「四段式」回复 + 重试闭环。核心目标：**先自检、再交付；出错先归因、再修复、再复检**。

## 一、渲染前自检表（输出前逐条核对）

### 布局与坐标
- [ ] 画布宽固定 680，viewBox `0 0 680 <h>`（SVG）；HTML 用模板容器
- [ ] 列间距 ≥40，同层节点间距 ≥16
- [ ] 文字与边框 padding ≥12
- [ ] 坐标预演（Mental Sandbox）已做，无坐标冲突、无节点重叠

### 文字与连线安全
- [ ] 文字与连线净空 ≥8px
- [ ] 箭头端点 10px 半径内无文字
- [ ] 连线不横穿任何文字
- [ ] 箭头文字避让已落实：`dy=-10` / `dx=10` 偏移，或文字下方垫白底矩形

### 语义与类型
- [ ] 用户给的文件 / 名词已拍平为自包含语义（解引用一切）
- [ ] 每条关系可复述为明确语句（论证而非展示）
- [ ] 一图一主题，粒度一致，装不下已拆分
- [ ] 图类型落在能力边界 ✅ 区；❌ 区已「说明不支持 + 原因 + 替代」并等确认

### 轨道合规
- [ ] HTML：单文件、零 CDN、系统字体、暖色基调
- [ ] SVG：`<svg>` 开头、无 DOCTYPE/html/head/body；箭头用 `<marker orient="auto">`；中文 `font-family="sans-serif"`
- [ ] Mermaid：语法正确、可粘贴渲染

## 二、四段式出错回复

遇到渲染异常（压字、重叠、箭头反向、类型不支持、文件报错等），按以下结构回复，**先现象，后原因，再修复，最后重试校验**：

```
【现象】描述具体表现（如「订单服务卡片与连线文字重叠」）。
【原因】定位根因（如「箭头标签放在端点 6px 内，且未垫白底」）。
【修复】给出改动（如「标签整体下移 dy=-10 并加白底矩形」）。
【重试校验】说明已重新跑自检表对应条目，确认通过后再交付。
```

## 三、常见错误 → 修复对照

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 文字压在连线 / 箭头上 | 标签落在端点 10px 内或未避让 | 偏移 `dy=-10`/`dx=10`，或垫白底；保证净空 ≥8px |
| 两个节点叠在一起 | 坐标预演缺失 / 同列 y 相同 | 重做坐标预演，同层 y 错开 ≥16 |
| 箭头方向反了 | `<marker orient>` 未设 `auto` 或路径反向 | 路径方向与语义一致，`orient="auto"` |
| 中文显示为方块 | HTML 未设 `charset` 或 SVG 缺 `font-family` | HTML 加 `<meta charset="UTF-8">`；SVG 文字加 `font-family="sans-serif"` |
| 类型不支持仍硬画 | 未走能力边界预检 | 改走「说明不支持 + 原因 + 替代」并等确认 |
| 仅列名词成框，关系不清 | 违反「论证而非展示」 | 每条关系先写明确语句再落节点 |
| 外部字体 / CDN 加载失败 | 模板被加了外链 | 回退系统字体栈，删外链 |

## 四、重试闭环（强制）

1. 任一条自检不过 → **先改，不交付半成品**。
2. 修复后**必须重新逐条跑自检表对应项**。
3. 仅在全部通过后才向用户交付最终图。
4. 同一问题重试 >3 次仍失败：停下，向用户说明卡点（坐标/语义/渲染环境），给出降级方案（如改用 Mermaid 或简化节点）。
