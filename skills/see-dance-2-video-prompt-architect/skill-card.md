## Description:

Turn rough video ideas into structured English or Chinese Seedance-oriented prompt packs, exact reference bindings, shot sequences, and focused debugging loops.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators, marketers, and video workflow users use this skill to turn rough text-to-video, image-to-video, multimodal reference, product clip, cinematic scene, transition, loop, or sequence ideas into structured prompts and focused revision plans.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Optional MCP setup installs and runs a GitHub-hosted helper package.

Mitigation: Only enable the optional MCP after trusting the referenced GitHub package; the core prompt-writing workflow does not require it.

Risk: Generated prompts could imply unsupported model controls, limits, prices, availability, or provider behavior.

Mitigation: Use the current product interface when exact settings matter and avoid presenting the skill as official ByteDance, Seedance, or provider documentation.
