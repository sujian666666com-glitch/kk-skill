# 合同瞄 · AI合同审核Skill

> 签合同前，先瞄一眼。

AI合同审核工具 — 三层审核架构（规则引擎 + AI语义分析 + 民法典背书），帮你在签合同前快速识别风险。

## 功能

- **L1 规则引擎**：自动检查6项必备条款（违约责任、保密条款、争议解决、付款条款、知识产权、廉洁条款）+ 合同基本信息完整性
- **L2 AI语义分析**：深度审查权利义务失衡、模糊表述、隐性费用、终止条件等10大风险维度
- **L3 民法典背书**：引用《民法典》相关条款提供法律依据
- **风险评分**：0-100分量化评估，按高/中/低风险分级展示
- **HTML报告**：生成专业美观的审核报告，含统计卡片、问题列表、条款检查表

## 使用

在对话中说：
- "帮我审核这份合同"
- "看看这个合同有没有问题"
- "合同风险检查"

然后粘贴合同文本或上传 .docx/.pdf 文件即可。

## 审核维度

| 维度 | 说明 |
|------|------|
| 必备条款检查 | 违约责任、保密、争议解决、付款、知识产权、廉洁 |
| 基本信息检查 | 合同编号、甲乙方名称、签署日期 |
| 权利义务失衡 | 单方面加重责任、减轻对方责任 |
| 模糊表述 | "视情况"、"另行约定"等模糊用语 |
| 隐性费用 | 未明示的额外费用或自动续费 |
| 终止条件 | 合同终止/解除条件是否对等 |
| 管辖风险 | 争议解决条款是否约定对方所在地管辖 |
| 金额风险 | 大小写一致性、币种明确性 |
| 签章要求 | 公章、法定代表人签字要求 |

## 技术来源

基于「合同瞄 v4」Web应用的审核逻辑封装，原始项目技术栈：Python Flask + DeepSeek API + 民法典1260条全文匹配。
