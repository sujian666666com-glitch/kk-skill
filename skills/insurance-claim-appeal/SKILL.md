# 保险理赔纠纷维权辅助分析

## 概述

本技能为保险顾问（代理人/经纪人）提供结构化的理赔拒赔案件分析流程。核心价值：将一份拒赔通知书 + 保单条款 + 病历材料，转化为可执行的维权方案。

用户身份：大童保险服务保险代理人（小包总），从业8年，中介平台，可跨公司比较产品。主业健康险（医疗险+重疾险），专注非标体客户。

## 工作流程

按以下五步流程执行，不可跳过步骤。

### 第一步：案件信息收集

从用户提供的材料中提取以下关键信息。信息不完整时，逐项向用户确认。

**必收信息：**
1. 保单基本信息：保险公司、险种全称、保单号、投保日期、保额/保费
2. 投保情况：线上/线下、是否经过健康告知、告知了哪些内容
3. 出险信息：出险时间、事故类型（疾病/意外）、就医经过、诊断结果
4. 拒赔信息：拒赔通知书原文（拍照/截图/文字）、拒赔日期
5. 理赔金额：客户申请赔付的具体金额

**选收信息（根据拒赔类型）：**
- 未如实告知拒赔 → 投保时健康告知问卷内容、客户投保前就诊/体检记录
- 既往症拒赔 → 投保前就诊病历、诊断记录
- 疾病定义争议 → 完整诊断报告、检查结果、医生意见
- 等待期出险 → 精确的确诊日期证据

### 第二步：拒赔依据拆解

`references/rejection_scenarios.md` 提供了六大常见拒赔场景的分析框架。根据本案的拒赔理由，加载对应的场景章节，逐条拆解：

1. 保险公司引用了保单哪一条款？
2. 该条款是否属于免责条款？是否履行了提示和明确说明义务？
3. 条款表述是否存在歧义？是否可适用"不利解释规则"（保险法第30条）？
4. 拒赔所依据的事实是否有证据支撑？举证责任在哪一方？

**输出格式：**
```
## 拒赔通知拆解

### 拒赔理由一：[理由原文]
- 依据条款：[条款编号和原文]
- 条款性质：[免责条款/一般条款/...]
- 存在的问题：[逐条指出]
- 反驳依据：[法律/条款/事实]
- 应对策略：[一句话总结]
```

### 第三步：维权策略制定

加载 `references/appeal_paths.md`，按以下顺序排列维权路径：

1. **内部申诉（优先）** — 何时适用、操作要点
2. **12378监管投诉** — 需要准备什么、预期效果
3. **行业调解** — 是否适合本案
4. **诉讼/仲裁** — 作为最后手段评估

对每条路径给出：
- 适用性评估（高/中/低）
- 时间预期
- 成功概率判断（基于法律依据和事实证据，使用"有一定把握""存在争议空间""较为困难"等表述，不承诺结果）
- 具体操作步骤

### 第四步：证据准备清单

加载 `assets/evidence_checklist.md`，标记：
- 已有材料
- 需补充材料及获取方式
- 关键证据（最能支持拒赔理由不成立的那些材料）

### 第五步：交付物生成

根据维权策略和用户需求，生成以下一项或多项：

1. **理赔申诉函** — 参照 `assets/appeal_letter_template.md`，填充案件具体内容
2. **12378投诉申请书** — 参照 `assets/complaint_letter_template.md`
3. **证据材料清单** — 基于 `assets/evidence_checklist.md` 生成定制版

## 法律依据引用

`references/legal_basis.md` 汇总了核心法条。在分析中引用法条时：
- 注明法条编号和关键内容
- 说明该法条如何适用于本案
- 如引用判例原则，标注"司法实践中"或"部分案例支持"

## 合规要求（强制）

加载 `references/compliance.md`，严格遵守：

1. **不承诺结果** — 说明维权路径和可能性，不承诺"一定能赔"
2. **不编造数据** — 条款引用必须基于用户提供的实际保单
3. **不越界执业** — 诉讼实质性建议提示找律师，医疗判断提示以医生意见为准
4. **每次输出末尾附合规声明模板**

## 输出交付标准

最终输出应包含：

```
一、案件信息摘要
二、拒赔通知拆解（逐条分析）
三、维权路径建议（按优先级排列，含操作步骤）
四、证据材料清单（已有/待获取）
五、交付物（申诉函/投诉书/证据清单）
六、重要提示（含合规声明）
```
